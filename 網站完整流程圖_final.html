🔄 完整流程說明

📍 主要流程路徑

快速申請流程： 首頁 → 簽證類型頁 → 簽證選擇頁 → 種類確認頁 → 訂單確認頁 → 支付頁 → 訂單查詢頁

登入流程： 首頁 → 登入頁 (Google OAuth) → 簽證類型頁

🔐 登入機制

  • 首頁提供「Google登入」按鈕
  • 點擊後導向登入頁進行Google OAuth驗證
  • 成功驗證後自動跳轉至簽證類型頁
  • 登入狀態在entire session保留

🔒 訂單確認頁登入檢查

  • 強制登入要求：訂單確認頁前必須先登入
  • 流程：
    • 用戶點擊「下一步」進入訂單確認頁
    • 系統檢查登入狀態
    • 未登入 → 自動跳轉至登入頁
    • 已登入 → 直接進入訂單確認頁
  • 登入後返回：Google OAuth 驗證完成後自動返回訂單確認頁（不返回首頁或簽證選擇頁）
  • 資料保留：跳轉登入前的所有選擇和輸入資訊都會保留，登入後可繼續進行

📅 訂單確認頁的日期修改邏輯

  • 訂單確認頁允許用戶修改出發日期
  • 種類確認頁不可修改出發日期（只作確認用）
  • 修改日期流程：
    • 點擊「修改出發日期」顯示日曆模式
    • 選擇新日期 → 自動更新簽證費用及工作天數
    • 系統根據新日期判斷快遞方式
  • 根據最終日期判斷：
    • 特定時間前 → 1日送達 (快遞費無料)
    • 其他時間 → 2日送達 (快遞費 ¥100 或 ¥150 根據類型)
  • 最終金額自動計算並顯示
  • 多申請人訂單共用同一LINE ID

💰 支付流程

  • 支付頁整合第三方支付閘道
  • 支持多種支付方式
  • 支付成功：自動跳轉至訂單查詢頁
  • 支付失敗：導向錯誤頁，用戶可選擇重試

📝 部落格導航 (外部連結)

  • 首頁提供「簽證常見問題▼」dropdown菜單
  • 包含多個國家簽證的外部連結
  • URL格式：https://{country}-visawang.tw/blog/
  • 例如：
    • 越南簽證 → https://vietnam-visawang.tw/blog/
    • 泰國簽證 → https://thailand-visawang.tw/blog/
    • 菲律賓簽證 → https://philippines-visawang.tw/blog/
  • 在新窗口打開外部部落格

🔙 返回按鈕的資料保留機制

  • 簽證選擇頁 ← 種類確認頁：保留已選擇的簽證信息
  • 種類確認頁 ← 訂單確認頁：保留申請人信息和簽證選擇
  • 訂單確認頁 ← 支付頁：保留完整訂單資料，用戶可修改或重新支付
  • 使用瀏覽器 session storage 或後端 session 保存資料

⚙️ 表單驗證規則

  • 電話號碼：必須符合 09XXXXXX 格式 (台灣手機)
  • 電子郵件：必須以 @gmail.com 或 @yahoo.com 結尾
  • 申請人資訊：支持多申請人，最多4人
  • LINE ID：所有申請人共用同一LINE ID

❌ 錯誤處理

  • 支付失敗時導向錯誤頁
  • 用戶可選擇「重試支付」返回支付頁
  • 或選擇「返回首頁」重新開始申請流程
  • 訂單狀態保留，允許後續重新提交

🎯 關鍵設計原則

  • 用戶友善：清晰的導航和直觀的流程
  • 資料保護：返回按鈕保留用戶已輸入的資訊
  • 彈性支付：失敗時允許重試而不失去訂單資料
  • 自動化：日期判斷和費用計算自動進行
  • 多申請人：支持一個訂單中多個申請人，共享LINE ID
  • 外部資源：部落格內容連結到外部簽證官網，保持主網站簡潔
